## 二、交付物清单（对照 M1 执行计划）

### 功能主链路（W1~W6）
- **接入层**：Prometheus 拉取 + Alertmanager/Webhook 推送 + pull 定时拉取（只上报变化），injest_queue 异步汇流，幂等三层（L0 幂等键 / L1 簇关联 / L2 相似提示不自动合并）。
- **降噪引擎**：Fingerprint（FNV-1a）→ 固定窗口去重 → 时间窗聚类 + 故障域聚合 → 影子判决，逐告警落库（Redis + TimescaleDB 双写），清 Redis 重建演练通过（miniredis 真实协议）。
- **拓扑**：自动发现 + CausalSubgraph 硬门禁（置信度三色，ADR-007）+ 挂起补边 + 千节点聚合下钻。
- **事件域双链路**：人工建单（审计 created_by）∥ 外部自动导入（代际演进 M9，复发新建不重开）；状态机 `open→acked→mitigated→resolved`，转 acked 即 manual_only（R2）；90d 归档（JSONB 快照）。
- **API 面**：gRPC SemanticModel + REST 只读网关 + SSE 实时流 + 写路径 Token 门禁 + 非 loopback 无 token 拒启（D1）。
- **控制台**：单文件 go:embed（EagleOps 原型皮肤），总览/告警中心（知识库富化：标题/级别/错误码/指标阈值/影响/措施）/事件页（分页、过滤、操作闭环、合并、审计轨迹）三视图，响应式双断点。

### 质量与工程
- **测试**：20 包中 17 包有测试（3 个为无逻辑工具包），全绿（含 `OPS_TEST_PG_DSN` 门控真库测试）；gofmt/vet 干净；CI 含 vet 与多平台冒烟。
- **审核闭环**：八轮全局审核/扫描/复审，累计闭环 **50+ 项实质问题**（第六轮评级 A-，第七轮高 3/中 11/低 18 全部第一二梯队修完）。遗留项均"刻意留下"且理由入档。
- **安全**：CVE 清零（govulncheck 复扫无发现；grpc 1.83.2 / x/net 0.59.0 / go-redis 9.6.3）、存储型 XSS 修复、SQLSTATE 哨兵消文案匹配、日志注入防护、恒定时间比较。
- **性能（口径③）**：100 并发 500 单——人工建单 P95 **73.5ms**、流转 **66.1ms**、列表 **95.0ms**（000007 索引后），RPS ~1240，零失败，工具退出码 0。压测期间揪出并修复 fillClusters N+1（3737ms→95ms，~39×）。
