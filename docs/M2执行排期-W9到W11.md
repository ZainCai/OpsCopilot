## 关键依赖与风险

```
W9-1 转正开关 ──→ W9-2 通知 ──→ W9-3 升级规则
                    └────────→ W10-4 autoCreate（依赖通知闭环可用）
W10-1 时间线 ──→ W10-3 KPI；W10-2 SLA 独立
W11-1 RCA ──→ W11-2 标注 ──→ W11-3 画布高亮
W11-6 upgrade ──→ 私有化交付（M2 内必须闭环，方案 B 承诺）
```

| 风险 | 缓解 |
|------|------|
| enforce 误拦截（评估环境≠生产分布） | 默认 shadow、按租户灰度、一键回退（W9-1 ADR 硬性要求）；enforce 首周 shadow 双跑对比 |
| 通知风暴（簇分裂/代际复发） | 复用建单限流 + 渠道级聚合计数；每渠道每簇冷却窗 |
| RCA 算法命中率不达标 | 已知答案只有 4 场景，命中率指标先按 ≥75% 定级，不达标降级"证据展示"而非"根因断言" |
| 代理 502 推送中断（常态化） | 本地提交纪律不变，网络恢复即推；关键节点（W 周出口）必须确认远端同步 |
