## 二、关键决策与保留

1. **置信度不跟原型的百分比条**：保留 ADR-007 三段格（high/medium/low 语义 ≠ 百分比臆造），仅对齐色板尺寸。
2. **拓扑画布不换渲染器**：自绘 SVG+foreignObject 保留（节点卡信息密度高于原型 SVG rect）；层级布局/大规模痛点触发时评估 AntV G6（结论出自 Neo4j 分析：换渲染层不换存储）。
3. **kpi-grid 保留 auto-fit**：原型定 5 列的前提是固定 5 卡，我们 4~5 浮动，不强抄。
4. **浅色双通道**：系统跟随为默认 + `[data-theme]` 手动钩子（无切换 UI = 不新增功能）。
5. **审计"查审计留痕"缓拍**：本期 metrics 计数替代，与哈希链/独立实例同归 M3（ADR-005 文末注记）。

## 三、后端契约偏差修正（文档以 Go 为准）

- 渠道字段是 `kind∈generic|feishu|wecom`（非 "type=webhook"）；REST 无 timeout 字段；upsert 幂等覆盖永不 409。
